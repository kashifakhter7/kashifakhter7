## 🚀 Projects

Here are some of my featured Machine Learning, Data Science, and NLP projects:

### 🎗️ [Breast Cancer Detection & Classification](https://github.com/kashifakhter7/Breast_Cancer_Detection)
* **Description:** An end-to-end clinical diagnostic machine learning application that predicts whether breast tumor tissue is benign or malignant based on 30 pathological cell nucleus biomarkers from FNA biopsy images.
* **Key Highlights:** Benchmarked 11 classification models, achieving over **95.6% accuracy** and **97.1% recall**, with feature scaling (`StandardScaler`) and an interactive clinical web interface.
* **Tech Stack:** `Python` `Scikit-Learn` `Streamlit` `Pandas` `NumPy`
* **Link:** [View Repository](https://github.com/kashifakhter7/Breast_Cancer_Detection)

### 🩺 [Diabetes Prediction System](https://github.com/kashifakhter7/Diabetes-Prediction)
* **Description:** A healthcare diagnostic support system leveraging Machine Learning to predict diabetes onset based on standard diagnostic measurements from the Pima Indians dataset.
* **Key Highlights:** Evaluated 11 machine learning algorithms, identified an optimized AdaBoost classifier (~78% accuracy), and deployed a real-time risk assessment tool via Streamlit.
* **Tech Stack:** `Python` `Scikit-Learn` `Streamlit` `Pandas` `NumPy`
* **Link:** [View Repository](https://github.com/kashifakhter7/Diabetes-Prediction)

### 📩 [SMS & Email Spam Classifier](https://github.com/kashifakhter7/Spam-Prediction)
* **Description:** A high-precision Natural Language Processing (NLP) classifier designed to detect and filter unsolicited spam, promotional fraud, and phishing messages across SMS and email channels.
* **Key Highlights:** End-to-end NLP text preprocessing (tokenization, stop-word removal, Porter stemming), TF-IDF vectorization, and a Multinomial Naïve Bayes model achieving **100% precision (zero false positives)** with an interactive dashboard.
* **Tech Stack:** `Python` `NLP` `NLTK` `Scikit-Learn` `Streamlit`
* **Link:** [View Repository](https://github.com/kashifakhter7/Spam-Prediction)
